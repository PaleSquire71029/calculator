安全与备份

备份、导入配置与安全提示。

1
设置管理密码

在 Cloudflare Worker Secrets 中设置 ADMIN_PASSWORD，使用强密码。

2
后台数据持久化

配置保存在 Worker 后端；管理登录会话有时效。

3
密钥处理

自定义 API Key 加密保存且不会回显；“改用 Worker Secret”会切回后端的 AI_API_KEY。

4
导出 / 导入配置

备份不包含 API Key，但会包含提示词。

5
安全边界

提问和图片会发送到所选模型服务商。发现异常用量时请轮换 API Key。

6
独立密钥（推荐）

在 Worker Secrets 中分别设置随机的 ADMIN_SESSION_SECRET 与 ADMIN_ENCRYPTION_KEY，建议各至少 32 个随机字符并妥善保管。添加后重新打开本页一次，让旧的自定义 API Key 自动迁移加密，再轮换管理密码；不要把这些密钥写入仓库。

配置文件与维护

重置统计不会删除模型配置或提示词。
